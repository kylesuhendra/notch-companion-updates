# Notch Companion

A macOS menu bar companion made by Kyle Suhendra. Requires an Apple silicon Mac running macOS 14 or later.

## Install

1. Visit the [Notch Companion update page](https://notch-companion.kyle-suhendra.chatgpt.site/updates/) and choose **Download for Mac**.
2. Open the disk image and double-click **Notch Companion**.
3. Choose **Install & Connect**. If you already have an older copy, choose **Update**. The app keeps your settings and hook connection.

The personal build is signed locally and hasn’t been notarized by Apple. macOS may ask for first-open approval. [Apple’s instructions](https://support.apple.com/en-us/102445)

## Get future updates

The running app checks its signed release feed automatically. From 1.17.2, click **Update available** on the island to see the website link. Open it for the latest installer and instructions, or choose **Dismiss This Version** to hide the notice. You can check again from the menu bar. [Notch Companion update page](https://notch-companion.kyle-suhendra.chatgpt.site/updates/)
